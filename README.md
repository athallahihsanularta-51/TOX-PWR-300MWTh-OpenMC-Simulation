# TOX-PWR-300MWTh-OpenMC-Simulation
Judul Penelitian :  Studi Desain Sel Bahan Bakar Thorium Oxide (TOX) dengan Variasi Enrichment Uranium-235 untuk Pressurized Water Reactor (PWR) 300 MWTh Menggunakan Perangkat Lunak OPEN MC

Penelitian ini memanfaatkan OpenMC untuk melakukan perhitungan neutronik sel bahan bakar TOX dengan variasi enrichment U-235 pada PWR berdaya 300 MWTh. Dari perhitungan diperoleh parameter level burn up, faktor multiplikasi efektif, distribusi fluks, conversion ratio, dan densitas atom pada reaktor. Parmater-parameter tersebut menjadi fokus utama untuk meninjau variasi bahan bakar yang optimal pada PWR 300 MWTh berbahan bakar TOX, bermoderator air, untuk periode burn up 720 hari.
